\# FPSH

Fourier-plane angular selection for Shack–Hartmann wavefront sensing



\## Overview



FPSH combines Fourier-plane angular selection with calibrated two-dimensional scanning to resolve focal-spot correspondence ambiguity and extend the effective measurement range of Shack–Hartmann wavefront sensing.



\## Code availability



The custom code used for focal-spot centroid extraction, valid-measurement selection, angular-compensation calibration, scan-state fusion, gradient recovery and quantitative analysis will be made publicly available in this repository upon publication.



During peer review, the code and associated documentation will be available to editors and reviewers upon request.
